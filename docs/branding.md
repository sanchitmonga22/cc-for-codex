# CC for Codex branding

The visual identity pairs a copper Claude Code mark with an ivory Codex terminal on tactile charcoal. The connected symbols represent two local agents working in the same workflow. This is an independent community project, not an official OpenAI or Anthropic product.

## Canonical assets

- [Square logo](../plugins/cc-for-codex/assets/icon.png): plugin composer icon, avatar, and README identity.
- [Wide logo](../plugins/cc-for-codex/assets/logo.png): plugin detail header; identical to the [README banner](assets/banner.png).
- Accent: copper `#D86A35`. Supporting colors: charcoal and warm ivory.

Use the PNG originals. Preserve aspect ratio, keep the full artwork visible, and do not stretch, recolor, or recreate these as simplified SVG substitutes. The square mark and wide banner are distinct compositions, not crops of one another.

The square logo was generated with the image-generation tool in Codex and approved by the maintainer. Direction: a square charcoal tile, embossed copper pixel Claude mark, ivory terminal glyph, subtle connecting trace, warm rim lighting, and no blue or purple. The approved wide banner was the style reference.

The plugin-browser screenshot documents a real earlier installation; its old icon is historical, not the current brand asset. Replace it only with a genuine capture after upgrading the plugin.
